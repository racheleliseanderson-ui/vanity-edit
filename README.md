# Vanity Edit

Improve this existing live application:

Application: https://makeup-intelligence.vercel.app/  GitHub Repository https://github.com/racheleliseanderson-ui/makeup-intelligence @connector:github:"GitHub API" 

Use the current live version as the baseline. Do not start from scratch — elevate what already exists.

Elevate Makeup Intelligence into a high-end, intelligent personal edit instrument under the Vanity or Vice philosophy.

Intelligence upgrades:

- Stronger multi-engine reasoning: skin + goals + lifestyle + maintenance tolerance + pancake risk should more deeply influence product type scoring, alternative pathways, tool necessity, and bag decisions.

- Live, transparent pancake-risk and architecture scoring that updates as the user adjusts inputs.

- Better “Build My Kit” and Bag Edit logic that respects complexity ceilings and desire without encouraging over-layering.

- Adaptive coaching that explains why a pathway scored the way it did.

Visual upgrades:

- Luminous, refined, editorial-luxury aesthetic appropriate to Vanity or Vice. Soft, sophisticated color, exceptional typography, elegant spectra and meters.

- Preset paths and the desk experience should feel desirable and high-end rather than utilitarian.

- Premium exportable “Edit Packet”.

Workflow:

- Start intelligent (presets) but allow deep revision of every field.

- Smooth movement between Match → Alternatives → Tools → Bag → Kit.

- Keep the philosophy intact: desire is allowed, the finish still has to earn the bag, architecture over cake.
